FTP 服务

[ftp]

传统 FTP 协议的监听地址与传输行为

关闭后不启动 FTP 监听，SFTP 不受影响。

默认开启

监听所用的 IPv4/IPv6 地址。0.0.0.0 表示监听全部网卡。

默认 0.0.0.0

FTP 控制连接端口。标准端口为 21，使用非特权端口可免 root 运行。

范围 1–65535，默认 21

客户端登录成功后显示在 220 响应中的文本。

默认 Welcome to fftpd

控制通道与文件名使用的字符集，需与客户端协商一致。

默认 UTF-8

客户端未指定 TYPE 时使用的传输模式。

默认 binary

允许的数据连接建立方式。仅内网环境可考虑开放主动模式。

默认 passive_only

开启后允许 anonymous / ftp 用户免密码登录。

默认关闭

匿名登录后的根目录。留空 = 未设置（使用默认值）。

空串 = 未设置

PASV 数据连接可用的端口范围（含端点），需在防火墙放行。

–
默认 50000 – 51000

单个连接的最大传输速率，单位 KB/s。

0 = 不限速（默认）

NAT / 端口映射环境下，PASV 响应中回给客户端的外网地址。

空串 = 使用实际连接地址

建立连接后等待客户端响应的超时时间（秒）。

单位：秒，默认 15

连接无任何操作多久后自动断开（秒）。

单位：秒，默认 15

不在欢迎信息中暴露 fftpd 的版本号，降低信息泄露风险。

默认关闭（显示版本）

预绑定并复用被动端口池，可降低高频短连接的开销。

⚠ 已知限制：libunftp 0.23.1 停止后不释放预绑定的被动端口，运行期 restart 会失败（需重启 fftpd 进程），故默认关闭。

放宽对 NAT 后客户端地址不一致的校验。

默认开启

全局根目录，所有用户被限制在其下。留空 = 各用户 home。

空串 = 各用户 home

FTPS 加密

[ftp.ftps]

在 FTP 之上叠加 TLS 加密

开启后 FTP 服务支持 AUTH TLS 显式加密。

默认关闭

拒绝未加密的明文连接，必须先完成 TLS 握手。

默认关闭

X.509 证书文件（PEM）。留空 = 自动生成（rcgen 自签名）。

空串 = 自动生成

与证书匹配的私钥文件（PEM）。留空 = 自动生成。

空串 = 自动生成

SFTP 服务

[sftp]

基于 SSH 的安全文件传输

开启后监听 SSH 端口并提供 SFTP 子系统。

默认开启

SSH 监听所用的地址。

默认 0.0.0.0

SSH 服务端口，默认使用非 22 端口以避免与系统 sshd 冲突。

默认 2222

ed25519 主机私钥文件。留空 = 首次启动自动生成到默认位置。

空串 = ~/.local/state/fftpd/ssh_host_ed25519_key

单次连接允许的密码 / 公钥认证失败次数，超出即断开。

默认 3

等待客户端完成认证的最长时间（秒）。

单位：秒，默认 60

SFTP 子系统自身的日志详细程度。

默认 info

限制同一账号同时建立的 SFTP 会话数量。

默认 5

定期重新生成 SSH 主机密钥，单位为天。

0 = 不轮换（默认）

安全策略

[security]

连接限制、IP 黑白名单与暴力破解防护

所有协议合计的同时在线连接上限。

默认 100

限制单个来源 IP 的并发连接，防止单点占满连接池。

默认 10

仅允许列表内的 IP / CIDR 连接。输入后按回车添加。

默认 0.0.0.0/0（允许所有 IPv4）

拒绝列表内的 IP / CIDR 连接，优先级高于白名单。

默认空列表

内置的失败计数封禁机制，达到阈值后临时拉黑来源 IP。

默认关闭

同一 IP 在统计窗口内允许的失败次数，超出即封禁。

默认 5 次

命中阈值后拉黑该 IP 的持续时间。

单位：秒，默认 3600（1 小时）

是否允许跟随符号链接。开启后可能突破根目录限制，请谨慎。

默认关闭

单连接允许的登录失败次数上限。

默认 5

日志记录

[logging]

日志输出位置、级别与滚动策略

日志文件存放目录。留空 = 使用默认状态目录。

空串 = ~/.local/state/fftpd/logs

全局日志详细程度，级别越高输出越少。

默认 info

滚动归档保留的最大文件数量，超出后删除最旧的。

默认 10 个

单个日志文件达到该字节数后触发滚动。

单位：字节，默认 10485760 ≈ 10 MiB

以结构化 JSON 行输出，便于日志采集系统解析。

默认关闭（纯文本）

将日志同时推送到图形界面的日志面板。

默认开启
